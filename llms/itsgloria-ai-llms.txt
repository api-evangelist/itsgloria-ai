# Gloria

> Gloria (Gloria AI Ltd., a Crypto Briefing product) is an AI-powered crypto and prediction-market news intelligence platform: curated real-time headlines with sentiment, entities, narratives, category recaps and articles, exposed as a REST API, a WebSocket feed, a hosted MCP server and an x402 pay-per-request API.

This file was generated by API Evangelist from the provider's public surface (no /llms.txt is published on itsgloria.ai or docs.itsgloria.ai as of 2026-09-19). Profile: https://apis.io/providers/itsgloria-ai/

## APIs

- [Gloria Data Platform REST API](https://docs.itsgloria.ai/gloria-data-platform/api-integration/): 20 operations - news, news by id, ticker summary, articles, recaps, narratives, feed categories, API tokens, social bots, WebSocket, health. Base URL https://ai-hub.cryptobriefing.com. Auth: JWT via SIWE wallet signature, long-lived API token, or anonymous public token (Bearer header or ?token=).
- [Gloria x402 API](https://docs.itsgloria.ai/gloria-data-platform/x402-integration/): GET https://api.itsgloria.ai/news ($0.03), /news-ticker-summary ($0.031), /news-by-keyword ($0.05), /recaps ($0.10) - HTTP 402 x402 v1 challenge, USDC on Base, no account or API key.
- [Gloria MCP Server](https://www.itsgloria.ai/mcp): Streamable HTTP at https://mcp.itsgloria.ai/mcp - 7 tools (get_latest_news, get_news_recap, search_news, get_categories, get_news_item free; get_enriched_news, get_ticker_summary via x402); anonymous initialize and tools/list. Also `pip install gloria-mcp` for stdio.

## Agent notes

- Errors are `{"detail": "..."}`; 401 missing/invalid token, 403 token lacks the feed category, 404 no data, 402 on the x402 host only.
- Pagination is page + limit on /news and /articles; responses are bare arrays with no has_more.
- No idempotency key; the only writes are API-token and bot registration (each has a reversal: revoke / delete). No rate-limit headers; Elite quota 50k requests/month.
